# Governance

Stein has a single maintainer. Only the Stein Client, the launcher, is proprietary and developed privately; everything
else in the Stein Project is open source and takes contributions in its repositories here.

## Roles

- **Maintainer / owner**: [Breno Xavier](https://github.com/brenoxavier). Sets the direction, reviews and merges
  pull requests, decides on features and API changes, cuts releases, and owns the Stein name and logo (see
  [TRADEMARK.md](TRADEMARK.md)).
- **Contributors**: anyone who opens an issue or a pull request in a Stein Project repository. Regular contributors may
  be invited to help with triage or review; merge rights stay with the maintainer unless this document says
  otherwise.

## How decisions are made

- Bugs and small improvements: decided in the pull request.
- Features, removals, anything that changes what players see: proposed in an issue first; the maintainer decides,
  after discussion when it is useful.
- Requests for the mod API go to an issue in the Loader repository, and requests for the Stein Client to an issue in
  any public repository or to the
  [Discord](https://discord.gg/MEHE9b5bjj); the maintainer decides whether and how they land.
- The maintainer may decline any contribution, and will say why.

## Releases

Each component is versioned and released on its own (`0.x` while the API is experimental). Release notes are
written by the maintainer, in English and Portuguese. Official builds are published only by the maintainer.

## Changes to this document

Only the maintainer changes this document.
