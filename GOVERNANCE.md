# Governance

Stein is an open-source project with a single maintainer.

## Roles

- **Maintainer / owner**: [Breno Xavier](https://github.com/brenoxavier). Sets the direction, reviews and merges
  pull requests, decides on features and API changes, cuts releases, and owns the Stein name and logo (see
  [TRADEMARK.md](TRADEMARK.md)).
- **Contributors**: anyone who opens an issue or a pull request. Regular contributors may be invited to help with
  triage or review; merge rights stay with the maintainer unless this document says otherwise.

## How decisions are made

- Bugs and small improvements: decided in the pull request.
- Features, new API, removals, anything that changes what players see: proposed in an issue first; the
  maintainer decides, after discussion when it is useful.
- The maintainer may decline any contribution, and will say why.

## Releases

Each repository is versioned and released on its own (`0.x` while the API is experimental). Release notes are
written by the maintainer, in English and Portuguese. Official builds are published only from this organisation.

## Changes to this document

Only the maintainer changes this document.
