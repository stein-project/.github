# Security Policy

If you find a security problem in any Stein repository, **do not open a public issue.** Examples: a way for a server
or a mod to run code it should not, account or token exposure, or a problem in the installer or update path.

Report it privately with [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on the affected repository (**Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it and which version you tested. You will get an answer as soon as
possible, and credit in the fix's release notes if you want it.

Only the latest release of each component receives security fixes.
