# Code of Conduct

Stein is a project people work on in their free time. Keep it a place where they want to stay.

## Expected

- Be respectful and assume good faith. Disagree with ideas, not with people.
- Be patient with newcomers and with questions that were asked before.
- Keep discussions on topic and constructive: say what is wrong and how it could be better.
- Respect the maintainer's decisions about the project, even when you disagree.

## Not accepted

- Harassment, insults, discrimination or personal attacks, in any form.
- Sharing someone's private information without permission.
- Spam, advertising, or using the project's spaces to promote cheats or to harm servers and players.
- Posting game code, decompiled code or content you do not have the right to share.

## Enforcement

The maintainer may edit or remove comments, close issues and pull requests, and block people from the
organisation when this code is not respected. Report problems privately to
[@brenoxavier](https://github.com/brenoxavier) (for example through the security reporting form of any
repository, which is private).

This code applies to all Stein Project spaces: repositories, issues, pull requests, discussions and official
community channels.
